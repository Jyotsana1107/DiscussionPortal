# Discussion Portal

## Overview

**Discussion Portal** is an interactive discussion platform created as a practice project to understand how a browser-based application can manage and display structured discussion data.

The platform allows users to explore discussions, search for topics, mark discussions as favourites, vote on posts, and view or add responses.

The project also provided practical experience with **JSON-based data handling, JavaScript, DOM manipulation, and interactive user interfaces**.

---

## Features

* Browse discussion topics
* Search discussions
* View discussion details
* Add and view responses
* Vote on discussions
* Mark discussions as favourites
* View favourite discussions
* Dynamically update discussion information
* Handle structured data using JSON
* Interactive browser-based interface

---

## Core Functionality

### Discussion Search

Users can search through available discussions to quickly find topics matching their interests.

The search functionality dynamically filters the available discussion data based on the user's input.

### Voting

Users can interact with discussions through voting functionality.

Votes are reflected in the discussion interface, allowing users to see engagement with different topics.

### Favourites

Users can mark discussions as **favourites** for easier access.

The favourite functionality provides a way to separate discussions that users want to revisit from the rest of the available content.

### Responses

Discussions support responses, allowing users to view and participate in conversations around a topic.

### JSON Data

The project uses **JSON** to represent and work with structured discussion data.

This provided practice with:

* JSON objects
* JSON arrays
* Reading structured data
* Accessing nested values
* Updating application data
* Converting data for use within JavaScript

1. Clone or download the repository.

4. Browse discussions and interact with the available features.

If the project loads JSON through JavaScript, running it through a local development server may be required depending on the browser's local-file restrictions.
